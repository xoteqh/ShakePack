How to use

📖 Основы работы

Этот плагин — твой быстрый помощник для создания крутых шейков в After Effects.

  • Применение: Выдели слой в таймлайне AE и нажми на текст любого шейка (например, "Soft Shake 1").
  • Случайный шейк: Нажми большую кнопку "RANDOM SHAKE", чтобы применить случайный пресет.
  • Превью: Нажми на иконку глаза 👁️ рядом с шейком, чтобы посмотреть, как он трясется.
  • Избранное: Нажми на звездочку ⭐, чтобы сохранить любимый шейк.
  • Темы: Нажми на палитру 🎨, чтобы изменить цвет интерфейса.

⚙️ Требования

Для работы плагина обязательно должен быть установлен Sapphire Plugin (эффекты S_Shake и S_DissolveShake).

📖 Basics

This plugin is your quick assistant for creating awesome shakes in After Effects.

  • Apply: Select a layer in the AE timeline and click on the text of any shake (e.g., "Soft Shake 1").
  • Random: Hit the big "RANDOM SHAKE" button to apply a random preset.
  • Preview: Click the eye icon 👁️ next to a shake to see how it animates.
  • Favorites: Click the star ⭐ to save a shake.
  • Themes: Click the palette 🎨 to change the UI color.

⚙️ Requirements

The Sapphire Plugin (S_Shake and S_DissolveShake effects) is required.
